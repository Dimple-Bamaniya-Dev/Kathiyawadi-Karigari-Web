# 🎨 Kathiyawadi Karigari Web

An **Art & Craft Business Website** built using **Angular**, **SCSS**, and **Bootstrap**, showcasing traditional Kathiyawadi handmade products.  
This project was developed, debugged, and deployed **step by step** using **GitHub Pages (free hosting)**.

🌐 **Live Website**  
https://dimple-bamaniya-dev.github.io/Kathiyawadi-Karigari-Web/

---

## 📌 Project Purpose

The goal of this project is to:
- Create a **live business website** for art & craft products
- Showcase **handmade Kathiyawadi items**
- Build a strong frontend base for **future ecommerce expansion**
- Deploy the site **without any hosting charges**

---

## 🛠️ Technologies Used

- **Frontend Framework:** Angular (Standalone Components)
- **Styling:** SCSS + Bootstrap 5
- **Language:** TypeScript
- **Version Control:** Git & GitHub
- **Hosting:** GitHub Pages (Free)
